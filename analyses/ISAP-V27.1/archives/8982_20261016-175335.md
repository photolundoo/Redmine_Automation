## 1. Étude du sujet

Le ticket décrit un délai d'environ quatre secondes à la connexion à la Main Courante lorsque le plugin vidéo est arrêté ou non déployé. Le signalement de l'absence du plugin n'apparaissait qu'après que le demandeur avait investigué. L'historique ne décrit pas le détail du correctif livré ; le ticket est néanmoins résolu le 17/08/2026.

## 2. Compte rendu de la situation

**Tenants.** Le problème a été observé sur le serveur VGP puis sur un poste de test avec le plugin vidéo arrêté. La configuration liée est indiquée dans le ticket #8941.

**Aboutissants.** Le ticket a été clôturé comme résolu. Aucun commentaire ne précise la solution livrée ni un seuil temporel d'acceptation.

**Objectifs du test.** Vérifier que l'absence du plugin vidéo n'empêche pas la connexion ni l'accès à la Main Courante, que son indisponibilité est signalée et que le client reste utilisable sans le délai bloquant décrit.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** `#8982` : non trouvé dans les plans consultés. La correspondance de « WebApp - Accès & Ressources » indique le plan 01 WebApp et MC01 — Généraux. MC01 vérifie l'accès à la page et la connexion, mais ne cite pas le plugin vidéo. Les mots-clés « timeout » et « plugin vidéo » ne révèlent pas d'étape équivalente dans MC01. MC05 — Onglet Vidéo traite l'affichage des flux avec le plugin lancé, pas l'indisponibilité du service pendant l'accès à la Main Courante.

**Comparaison des procédures.** Le parcours de connexion de MC01 est le même que celui nécessaire au ticket, mais ses prérequis ne couvrent pas le plugin arrêté. Il faut conserver ce parcours et ajouter un cas d'indisponibilité, en observant l'alerte et l'utilisation de l'interface. Aucun seuil autre que le délai observé dans le ticket n'est défini ; aucun seuil chiffré supplémentaire n'est proposé.

**Issue retenue.** B — Adapter l'existant : le test complète le parcours de connexion de MC01 par la condition particulière d'absence du plugin vidéo.

## 4. Procédure de test proposée

**Écarts avec la procédure existante.** Conserver les étapes de connexion et d'affichage de la page d'accueil de MC01. Ajouter le test ci-dessous avec le plugin vidéo arrêté ; ce scénario ne remplace pas les essais de flux vidéo avec le plugin disponible.

**Connexion sans plugin vidéo**
- Dans l'environnement de test, arrêter le plugin vidéo puis ouvrir la page de la Main Courante. Résultat attendu : la page de connexion s'affiche et reste utilisable. (#8982)
- Se connecter avec un compte de test autorisé. Résultat attendu : l'accès à la Main Courante aboutit et un signalement indique que le plugin vidéo est indisponible. (#8982)
- Utiliser une fonctionnalité de la Main Courante après l'affichage du signalement. Résultat attendu : le client reste réactif et le signalement n'empêche pas la navigation. (#8982)
