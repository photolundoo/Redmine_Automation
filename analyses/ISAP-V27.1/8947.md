## 1. Étude du sujet

Le ticket introduit une licence distincte par application WebApp, notamment pour Iris, Main Courante, Statistiques et Situation. Pour Situation, les licences de consultation et de partage sont distinguées.

## 2. Compte rendu de la situation

**Tenants.** Le modèle de licence devait permettre de commercialiser séparément les applications WebApp.

**Aboutissants.** Les applications sont désormais contrôlées par des licences dédiées.

**Objectifs du test.** Vérifier qu’une application licenciée est accessible et qu’une application non licenciée est indisponible sans perturber les autres.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** La recherche de #8947 dans le plan 01 ne retourne aucune étape. Le plan couvre les applications WebApp mais ne contient pas de recette de droits par licence.

Une fiche transverse doit être créée et soumise à décision humaine.

## 4. Procédure de test proposée

**Licences par application WebApp**
- Appliquer une licence de test autorisant une seule application WebApp, puis ouvrir le menu Applications. Résultat attendu : seule l’application licenciée est accessible. (#8947)
- Appliquer une licence désactivant une application puis essayer de l’ouvrir directement et depuis le menu. Résultat attendu : l’accès est refusé ou l’application est absente, sans erreur sur les applications autorisées. (#8947)
- Tester séparément les licences Situation et Partage de situation. Résultat attendu : chaque capacité suit la licence qui lui est propre. (#8947)

## 5. Intégration proposée

Créer une fiche **Licences WebApp** dans le plan 01 WebApp, à positionner avant les fiches applicatives.
