## 1. Étude du sujet

Le ticket demande un tableau de bord listant les capteurs filtrés par types et par valeurs d'attributs booléens, avec choix des colonnes à afficher. Les exemples décrivent des capteurs PAV pleins, des guichets non armés et des pannes. Le ticket précise qu'Active doit être vrai pour que les autres attributs temps réel soient pertinents. L'historique mentionne un test du tableau de bord PAV sur un environnement de test, mais n'en décrit pas les résultats fonctionnels.

## 2. Compte rendu de la situation

**Tenants.** Le sujet concerne le tableau de bord de la WebApp et l'affichage des attributs d'état des capteurs.

**Aboutissants.** Le ticket est résolu. L'historique indique qu'une V2 du cas devait être faite et qu'un essai de tableau de bord PAV a été réalisé ; la capture ne constitue pas à elle seule un résultat détaillé de validation pour les différents filtres demandés.

**Objectifs du test.** Vérifier dans un jeu de données contrôlé le filtrage de capteurs par types et attributs, ainsi que la sélection des colonnes visibles, sans conclure au-delà de la configuration et des résultats réellement observés.

## 4. Procédure de test proposée

**Configurer et vérifier les filtres du panneau de capteurs**
- Dans un tableau de bord modifiable, ajouter un panneau d'action pour les capteurs. Résultat attendu : le panneau s'affiche et liste les capteurs visibles dans le dossier courant. (#9035)
- Filtrer les types sur VERRE, EP et OM, puis régler Active et Triggered sur True. Résultat attendu : les lignes affichées correspondent aux capteurs visibles de ces types dont Active et Triggered sont vrais ; les autres types et valeurs ne figurent pas dans la liste filtrée. (#9035)
- Remplacer le filtre par le type ARME, Active = True et Triggered = False. Résultat attendu : les lignes affichées correspondent aux capteurs visibles qui satisfont ces critères. (#9035)
- Retirer le filtre de type, conserver Active = True et régler Failure = True. Résultat attendu : la liste contient les capteurs visibles de tous types satisfaisant ces attributs. (#9035)
- Dans les colonnes visibles, sélectionner DisplayName et Description. Résultat attendu : ces colonnes apparaissent dans le panneau ; toute autre colonne non sélectionnée est absente. (#9035)
