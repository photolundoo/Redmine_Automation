## 1. Étude du sujet

Le traitement d’une limite de licence inconnue pouvait provoquer un crash dans les applications utilisant le vérificateur de licence. Les composants concernés ont été recompilés.

## 2. Compte rendu de la situation

**Tenants.** Une évolution de licence ne devait pas interrompre les applications compilées avec le vérificateur.

**Aboutissants.** La lecture d’une limite non reconnue ne provoque plus d’arrêt.

**Objectifs du test.** Confirmer le démarrage stable avec une licence de test contenant une limite inconnue.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** La recherche de #8990 dans le plan 12 ne retourne aucune étape. **UPD02 — Monter de version** est la passe d’installation adaptée à cette non-régression.

La procédure s’ajoute à cette fiche.

## 4. Procédure de test proposée

**Licence à limite inconnue**
- Installer une licence de test contenant une limite non reconnue puis démarrer les applications concernées. Résultat attendu : les applications restent démarrées sans crash. (#8990)
- Exécuter un parcours de santé des applications disponibles. Résultat attendu : les fonctions accessibles répondent malgré la limite inconnue. (#8990)

## 5. Intégration proposée

Ajouter ces étapes à **UPD02 — Monter de version** du plan 12 Update version.
