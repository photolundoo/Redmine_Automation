## 1. Étude du sujet

Le ticket demande un tableau de bord qui liste les capteurs selon leurs types et leurs attributs booléens et permet de choisir les colonnes affichées. Les exemples sont les PAV pleins (VERRE, EP et OM avec Active et Triggered vrais), les guichets non armés (ARME, Active vrai et Triggered faux) et les pannes (tous types, Active et Failure vrais). Le ticket précise que les autres attributs ne sont pertinents que lorsque Active est vrai. L'historique rapporte un essai du tableau de bord PAV sur un environnement de test, sans détailler les résultats attendus ou constatés.

## 4. Procédure de test proposée

**Configurer et vérifier les filtres du panneau de capteurs**
- Dans un tableau de bord modifiable, ajouter un panneau d'action configuré pour les capteurs. Résultat attendu : le panneau apparaît et liste les capteurs accessibles dans le dossier sélectionné. (#9035)
- Configurer les types VERRE, EP et OM, puis régler Active et Triggered sur True. Résultat attendu : seules les lignes de capteurs visibles correspondant aux types choisis et aux deux états sont présentes. (#9035)
- Remplacer les filtres par le type ARME, Active = True et Triggered = False. Résultat attendu : les lignes restantes correspondent aux capteurs visibles satisfaisant ces critères. (#9035)
- Retirer le filtre de type, conserver Active = True et régler Failure = True. Résultat attendu : les capteurs visibles de tous types satisfaisant ces attributs apparaissent. (#9035)
- Dans les colonnes visibles, sélectionner DisplayName et Description. Résultat attendu : ces deux colonnes sont visibles et les colonnes non sélectionnées n'apparaissent pas. (#9035)
