## 1. Étude du sujet

Le ticket demande l'envoi automatique de messages WhatsApp associés aux incidents et aux PoliceLogs, avec filtrage par type et envoi à l'agent pris en charge ou à une liste prédéfinie liée à une SecurityCompany. Il demande aussi d'enregistrer dans la Main Courante les messages reçus des agents, pièces jointes comprises. L'historique décrit le plugin déployé dans la grille, le service de réception webhook, des essais de faisabilité et un test sur téléphone déclaré validé le 16/07/2026.

## 2. Compte rendu de la situation

**Tenants.** Le parcours met en jeu la Main Courante, un plugin de grille, un service webhook et un compte WhatsApp Business. L'historique mentionne les exigences de templates approuvés et de consentement des destinataires. Les identifiants, secrets et numéro de téléphone présents dans le ticket ne sont pas repris dans cette analyse.

**Aboutissants.** Le ticket est résolu et le plugin a été livré sur une grille. Les essais rapportés observent que plusieurs messages reçus dans la même minute sont regroupés dans le commentaire d'une mention, tandis qu'un message ultérieur crée une mention distincte ; la validation du test est indiquée. Le plan 13 comporte une rubrique « Plugin WhatsApp », mais aucune fiche identifiée ni procédure n'y est décrite.

**Objectifs du test.** Vérifier le routage des messages sortants selon les filtres et destinataires configurés et la restitution dans la Main Courante des messages entrants et pièces jointes. Reproduire le comportement de regroupement temporel explicitement constaté dans l'historique.

## 4. Procédure de test proposée

**Envoi de messages depuis la Main Courante**
- Configurer dans l'environnement de test un filtre d'envoi et un template approuvé, puis créer un incident du type filtré et pris en charge par un agent de test consentant. Résultat attendu : l'agent configuré reçoit le message correspondant à l'incident. (#8808)
- Créer un incident d'un type exclu par le filtre de test. Résultat attendu : aucun message associé à cet incident n'est envoyé au destinataire de test. (#8808)
- Créer un PoliceLog satisfaisant les critères configurés pour une SecurityCompany. Résultat attendu : les agents de test associés à cette liste reçoivent le message prévu et un destinataire non inclus ne le reçoit pas. (#8808)

**Réception des messages et pièces jointes**
- Répondre à un message depuis le téléphone de test avec un texte et une pièce jointe de test. Résultat attendu : le message entrant et la pièce jointe sont consultables dans la Main Courante selon le parcours livré. (#8808)
- Envoyer plusieurs messages pendant une même minute puis un autre message à une minute distincte. Résultat attendu : les messages de la même minute sont regroupés dans le commentaire d'une mention et le message envoyé à une minute distincte crée une mention distincte, comme indiqué dans le test validé du ticket. (#8808)
