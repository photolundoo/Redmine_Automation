## 1. Étude du sujet

Le ticket demande de mettre à jour commons-fileupload, commons-io, jakarta.mail et commons-lang après une analyse CyberVeille. Le dernier historique relève jakarta.mail 2.0.2, commons-fileupload 1.6.0 et commons-lang3 3.20.0, et indique qu’il n’y a plus de référence à commons-io. Le travail a été fait dans le cadre de #9033 ; l’analyse ci-dessous porte seulement sur #8915.

## 2. Compte rendu de la situation

**Tenants.** La demande porte sur la mise à jour de dépendances Java identifiées par CyberVeille. Les versions relevées dans le dernier suivi diffèrent de certaines versions souhaitées de la description initiale.

**Aboutissants.** Le dernier historique indique les versions déclarées pour trois packages et l’absence de référence à commons-io. Le ticket est résolu.

**Objectifs du test.** Vérifier les dépendances rapportées dans la livraison et s’assurer que les composants concernés démarrent sans erreur de résolution ou de chargement.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** La recherche de `#8915`, « Maven », « commons-fileupload », « commons-io », « jakarta.mail » et « commons-lang » ne donne aucune étape dédiée. La règle de correspondance classe les migrations de dépendances dans NRT01 du plan 12.

**Comparaison des procédures.** NRT01 prévoit le démarrage et le fonctionnement général des composants après une migration, mais ne vérifie pas les versions des packages Maven. Il faut donc compléter la fiche avec les contrôles précis rapportés par le ticket.

**Issue retenue.** Issue B — Adapter l’existant en ajoutant la vérification des dépendances déclarées et du démarrage de leurs composants consommateurs.

## 4. Procédure de test proposée

**Écarts avec la procédure existante.** Conserver les contrôles généraux de NRT01 et ajouter les vérifications de versions correspondant au dernier suivi, sans supposer de version de commons-io puisque le suivi signale l’absence de référence.

**Packages Maven — versions et démarrage**
- Dans les métadonnées de dépendances de la livraison, vérifier jakarta.mail, commons-fileupload et commons-lang3. Résultat attendu : les versions déclarées sont respectivement 2.0.2, 1.6.0 et 3.20.0. (#8915)
- Vérifier les métadonnées de dépendances livrées pour commons-io. Résultat attendu : aucune référence à ce package n’est présente, conformément au dernier suivi. (#8915)
- Démarrer les services Java concernés et consulter leurs journaux. Résultat attendu : aucun échec de démarrage dû à la résolution ou au chargement des dépendances mises à jour. (#8915)

## 5. Intégration proposée

Ajouter ces contrôles à **NRT01 — Passe de non-régression technique** du plan 12 Update version, sous le sous-titre **Packages Maven — versions et démarrage**.
