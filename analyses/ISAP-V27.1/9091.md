## 1. Étude du sujet

Le ticket traite le passage d'Ice 3.7.0 à Ice 3.7.11 pour la génération JavaScript. Selon la description, cette version générait des fichiers `.js` différents qui causaient des erreurs dans la configuration de l'environnement. Le 05/10/2026, le développeur indique que la génération des fichiers a été modifiée et que le JavaScript est désormais correct ; le ticket est résolu le 13/10/2026.

## 2. Compte rendu de la situation

**Tenants.** Le ticket concerne la génération des fichiers JavaScript nécessaires à la WebApp. Le contournement initial consistait à installer Ice 3.7.0 et à modifier l'environnement de génération ; le test doit porter sur la version migrée Ice 3.7.11, pas sur ce contournement.

**Aboutissants.** Le procédé de génération a été modifié et le JavaScript est rapporté correct. Le ticket ne décrit pas d'autre résultat de test.

**Objectifs du test.** Confirmer que la génération avec Ice 3.7.11 aboutit sans erreur et que la WebApp issue de cette génération s'ouvre et échange avec le serveur sans régression liée aux fichiers JavaScript.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** `#9091` : non trouvé dans les plans consultés. La recherche de « Ice 3.7.11 » et « Javascript » dans les plans 01 WebApp et 12 Update version ne trouve pas de procédure consacrée à cette migration. La correspondance classe les migrations de bibliothèques et dépendances comme « Non-régression technique » et les rattache à NRT01 — Passe de non-régression technique dans le plan 12.

**Comparaison des procédures.** NRT01 vérifie le démarrage des services de la grille, le lancement de la WebApp et les échanges avec le serveur, puis demande un sous-titre par composant migré. Elle couvre le test de fonctionnement général mais pas la génération des fichiers JavaScript par Ice 3.7.11 ; un sous-titre dédié complète donc la fiche.

**Issue retenue.** B — Adapter l'existant : ajouter à NRT01 le contrôle de génération des fichiers JavaScript avec Ice 3.7.11 et l'ouverture de la WebApp générée.

## 4. Procédure de test proposée

**Écarts avec la procédure existante.** Conserver les étapes générales de démarrage des services et de connexion à la WebApp de NRT01. Ajouter le sous-titre ci-dessous pour contrôler le composant Ice migré.

**Ice 3.7.11 — génération JavaScript**
- Générer les fichiers JavaScript de la livraison ISAP-V27.1 avec Ice 3.7.11. Résultat attendu : la génération se termine sans erreur et produit les fichiers JavaScript attendus par le build. (#9091)
- Déployer le build généré dans l'environnement WebApp de test et ouvrir la Main Courante. Résultat attendu : la page s'ouvre, les échanges avec le serveur s'effectuent et aucune erreur liée au JavaScript généré n'est observée. (#9091)
