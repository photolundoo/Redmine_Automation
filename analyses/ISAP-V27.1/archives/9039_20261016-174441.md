## 1. Étude du sujet

Le ticket porte sur la migration de Slice2VT vers Ice 3.7. La première compilation signalée échouait parce que l’en-tête `Slice/Preprocessor.h` était introuvable ; le suivi indique ensuite que la situation est considérée comme résolue, sans décrire de scénario fonctionnel supplémentaire.

## 2. Compte rendu de la situation

**Tenants.** Slice2VT est un outil C++ dépendant des composants Slice d’Ice. La migration modifie la disponibilité des en-têtes utilisés pour sa compilation.

**Aboutissants.** Le ticket est résolu après une analyse de l’évolution de l’API Slice dans Ice 3.7. Le dernier commentaire indique « OK en l’état », sans détailler les changements livrés.

**Objectifs du test.** Vérifier que Slice2VT se compile avec Ice 3.7 dans l’environnement Windows concerné et que l’erreur de fichier d’en-tête manquant ne se reproduit pas.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** La recherche de `#9039` dans les plans ne retourne aucune étape. Dans le plan 12, la fiche **NRT01 — Passe de non-régression technique** prévoit le contrôle des composants après migration de dépendance ; aucune étape ne nomme Ice, Slice2VT ou cet en-tête. La règle de correspondance classe les migrations de bibliothèques dans NRT01.

**Comparaison des procédures.** NRT01 prévoit le démarrage des services et applications après une mise à jour, mais Slice2VT est un outil de compilation et le ticket signale un échec de compilation. Une vérification de compilation spécifique à l’outil complète donc les contrôles généraux de la fiche.

**Issue retenue.** Issue B — Adapter l'existant : ajouter à NRT01 un contrôle de compilation de Slice2VT avec Ice 3.7, sans supposer un scénario de génération qui n’est pas décrit dans le ticket.

## 4. Procédure de test proposée

**Écarts avec la procédure existante.** Conserver les contrôles généraux de NRT01 et ajouter la compilation de Slice2VT avec la version d’Ice livrée.

**Ice 3.7 — Slice2VT**
- Dans l’environnement de compilation Windows prévu pour la livraison, reconstruire la cible Slice2VT avec Ice 3.7. Résultat attendu : la compilation aboutit sans erreur signalant l’absence de `Slice/Preprocessor.h`. (#9039)

## 5. Intégration proposée

Ajouter l’étape de compilation à **NRT01 — Passe de non-régression technique** du plan 12 Update version, sous le sous-titre **Ice 3.7 — Slice2VT**.
