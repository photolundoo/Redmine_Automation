## 1. Étude du sujet

Le ticket corrige l’importeur de planification pour prendre en charge les numéros de poste sous forme de texte et rattacher au dossier cible les entités réutilisées, notamment les prestataires. Il ajoute l’initialisation de huit tarifications à zéro par couple lot/type de poste, avec les calendriers associés. Le ticket est résolu, sans compte rendu de recette détaillé.

## 2. Compte rendu de la situation

**Tenants.** Un nouvel import dans un dossier parallèle pouvait réutiliser des prestataires sans créer leur lien avec ce dossier ; les tarifications initiales manquaient.

**Aboutissants.** L’importeur crée les liens de dossier nécessaires et initialise les tarifications et calendriers attendus.

**Objectifs du test.** Établir qu’un import est complet dans son dossier cible, conserve les numéros de poste texte et crée le jeu initial de tarifications à prix nul.

## 3. Comparaison avec l'existant

**Recherche dans les plans.** La recherche de #9089 dans le plan 14 Planification ne retourne aucune étape. Le plan couvre les fonctionnalités de planification, dont la configuration, les types de prestation, les lots, les prestataires et les calendriers, mais pas leur alimentation par PlanificationImporter.

Une fiche d’import est nécessaire ; son identifiant et sa position dans le plan doivent être validés.

## 4. Procédure de test proposée

**Import d’un dossier de planification**
- Importer un jeu de données contenant un numéro de poste alphanumérique dans un nouveau dossier de planification. Résultat attendu : l’import se termine sans erreur et le numéro de poste est conservé à l’identique. (#9089)
- Importer dans un dossier parallèle un prestataire déjà présent dans un autre dossier. Résultat attendu : le prestataire est réutilisé et rattaché au nouveau dossier sans suppression de son rattachement existant. (#9089)
- Ouvrir les données importées pour un couple lot/type de poste. Résultat attendu : huit tarifications à prix zéro sont créées pour les combinaisons jour/nuit et types de jour attendus. (#9089)
- Ouvrir les calendriers enfants des tarifications créées. Résultat attendu : chaque calendrier est lié à sa tarification et porte les plages horaires jour ou nuit attendues. (#9089)

## 5. Intégration proposée

Créer une fiche dédiée à PlanificationImporter dans le plan 14 Planification, avant les contrôles de configuration de planification afin de tester la disponibilité des données importées.
